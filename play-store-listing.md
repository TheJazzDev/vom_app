## Notes for Asset Creation

1. **Consistent Branding:** Use your church colors (#E5F2FF light, #0D0D2B dark) throughout all graphics
2. **Screenshot Best Practices:**
   - Use real app content (not lorem ipsum)
   - Show the app in light mode (or both light and dark)
   - Add device frames for professional look (optional)
   - Include brief captions or annotations
   - Ensure text is readable at thumbnail size
3. **Feature Graphic Tips:**
   - Include app icon
   - Add tagline: "Your Spiritual Companion"
   - Use compelling imagery (church, community, faith-related)
   - Make it visually striking to stand out in store
4. **Video Recommendations (if creating):**
   - 30-60 seconds duration
   - Show app navigation and key features
   - Include voiceover explaining benefits
   - End with call-to-action to download
